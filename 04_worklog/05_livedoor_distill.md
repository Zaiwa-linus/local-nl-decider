# 正解のある実データでの蒸留（livedoor ニュース）

パブコメには正解がなく、蒸留でどれだけ失うかを測れないので、人が付けたカテゴリーのある実データで同じことを試した。事故の記録のようなデータは題材として使わない。

## データ（16_fetch_livedoor.py）

- livedoor ニュースコーパス（株式会社ロンウイット、2012 年 9 月収集）。9 カテゴリー、7,367 件。CC BY-ND 2.1 JP
- カテゴリーは連載・サイトの名前（Sports Watch、ITライフハック、独女通信など）。文中に連載名が入っている記事が多い（Sports Watch はタイトルの 55%、S-MAX は本文のほぼ全件）。そのままだと連載名で当たってしまうので、取り除いた
- 判定に使う文は「タイトル＋本文」の先頭 500 文字
- カテゴリーの割合を保って、学習用 5,159 件・検証用 1,104 件・評価用 1,104 件に分けた

## 埋め込み（17_embed_livedoor.py）

| split | 件数 | 時間 | 速さ |
| --- | --- | --- | --- |
| train | 5,159 | 367.0 秒 | 14.1 件/秒 |
| validation | 1,104 | 76.9 秒 | 14.3 件/秒 |
| test | 1,104 | 78.1 秒 | 14.1 件/秒 |

文が長い（500 文字）ので、MASSIVE（約 250 件/秒）やパブコメ（35 件/秒）よりかなり遅い。

## ラベル付け（18_label_livedoor.py）

- deepseek-flash（思考なし）。連載名は渡さず、各カテゴリーの内容の説明だけを渡した
- 学習用と評価用の 6,263 件を 109.7 秒（57.1 件/秒）。入力 4,292,453 トークン（うちキャッシュ 1,257,344）、出力 51,959 トークン、形式不正 0 件

## 結果（19_distill_eval_livedoor.py、[03_results/04_livedoor/01_distill.md](../03_results/04_livedoor/01_distill.md)）

| | 評価用の正解率 | Macro-F1 |
| --- | --- | --- |
| 先生（DeepSeek）そのもの | 0.653 | – |
| DeepSeek のラベルで学習（5,159 件） | 0.652 | 0.630 |
| 正解のラベルで学習（5,159 件） | **0.881** | 0.875 |

| しきい値 | DeepSeek のラベルで学習: 回答率 / 正解率 | 正解のラベルで学習: 回答率 / 正解率 |
| --- | --- | --- |
| 0.8 | 0.763 / 0.724 | 0.771 / 0.965 |
| 0.9 | 0.638 / 0.763 | 0.639 / 0.977 |

- 正解のラベルで学習すると 88%。確信度 0.9 以上なら 64% を正解率 98% で答えられる。埋め込みは長いニュース記事でもよく効く
- **先生の正解率が 65% しかない**。DeepSeek のラベルで学習した判定機も 65% で、先生とほぼ同じところで止まる（評価用での先生との一致率は 85%）。学習件数を増やしても上がらない（500 件で 64%、全件で 65%）
- 先生の間違いの多くは「一般ニュース」への流れ込み（家電 → 一般ニュース 46 件など）と、IT・家電・スマートフォンの取り違え。カテゴリーは連載ごとの編集方針で決まっていて、内容の説明だけでは境目が分からない
- 正解のラベルで学習した判定機は、連載名を取り除いても 88% 当たる。文体や扱う題材の傾向といった、説明には書けない違いを例から学べている
- **わかったこと**: 蒸留した判定機は、先生の正解率を超えない。蒸留がうまくいくかは、先生がカテゴリーの境目を説明だけで判断できるかで決まる。MASSIVE（先生の一致率 90%）はできたが、livedoor（65%）はできなかった

## DeepSeek と正解が食い違った記事を目で確かめる

評価用で DeepSeek と正解が食い違った 383 件から、15 件を無作為に選んで読んだ（乱数の種は 1）。記事の本文は CC BY-ND なので、ここには載せない。

| 判断 | 件数 | 例 |
| --- | --- | --- |
| 内容だけで見ると DeepSeek のほうが妥当 | 7 | 映画のレビューが「独身女性のコラム」、RSS の使い方が「男性向け」、写真展が「IT」 |
| どちらとも言える | 6 | 海外ローミング（IT かスマートフォンか）、Ultrabook（IT か家電か）、メイク（独身女性のコラムか女性向けか） |
| DeepSeek の間違い | 2 | 男性のスーツのカタログを「女性向け」、接待やデートのゴルフマナーを「スポーツ」 |

- livedoor の正解は「どの連載に載ったか」で、内容から決めたラベルではない。DeepSeek の間違いとされた 35% の多くは、内容からは正解を決められない記事
- **正解のラベルで学習した判定機の 88% には、連載名の取り残しが効いている疑いがある**。【オトナ女子映画部】（独身女性のコラム）、【デジ通】（IT）、【話題】（家電）のような、連載の中のコーナー名が文に残っている（次の節で確かめた）

## コーナー名も取り除いて測り直す

【】で囲んだ部分が残っている記事は多かった。家電は 864 件中 804 件（【話題】が 775 件）、IT は 870 件中 434 件（【デジ通】など）、スマートフォンは 870 件中 396 件（【Androidアプリ】など）。
[16_fetch_livedoor.py](../01_scripts/16_fetch_livedoor.py) で【】で囲んだ部分をすべて取り除くようにして、データ・埋め込み・DeepSeek のラベル・評価をすべて作り直した。分け方（記事の並び）は前と同じ。前のデータは 02_data/livedoor/with_corner/ に残した。

- 埋め込み: 7,367 件で 515 秒（14.3 件/秒）
- DeepSeek（deepseek-flash、思考なし）: 6,263 件で 162.6 秒（38.5 件/秒）。入力 4,290,899 トークン（うちキャッシュ 2,505,649）、出力 51,945 トークン、形式不正 0 件

| | コーナー名あり | コーナー名なし |
| --- | --- | --- |
| 先生（DeepSeek）の正解率 | 0.653 | 0.643 |
| DeepSeek のラベルで学習した判定機 | 0.652 | 0.650 |
| 正解のラベルで学習した判定機 | 0.881 | **0.874** |
| 正解のラベル、確信度 0.9 以上（回答率 / 正解率） | 0.639 / 0.977 | 0.584 / 0.964 |
| 正解のラベル、家電の F1 | 0.866 | 0.803 |

- コーナー名の効きは小さかった。正解のラベルで学習した判定機は 88.1% → 87.4%。下がったのは主に家電（F1 0.866 → 0.803）で、【話題】に頼っていた分
- 確信度で絞ったときの回答率は下がった（0.9 以上で 64% → 58%）。コーナー名は、確信度を上げる手がかりになっていた
- 判定機が内容（題材・文体）から連載を見分けられる、という結論は変わらない。先生と蒸留した判定機が 65% 前後で止まる、という結論も変わらない
- 結果は [03_results/04_livedoor/01_distill.md](../03_results/04_livedoor/01_distill.md)（コーナー名なしに置き換えた）

## DeepSeek に例を見せてラベルを付ける（few-shot）

検証用（学習にも評価にも使わない）から、カテゴリーごとに 5 件、計 45 件の記事（先頭 200 文字）と正解を、プロンプトに例として入れた（[18_label_livedoor.py](../01_scripts/18_label_livedoor.py) の `--shots 5`）。カテゴリーの説明は前と同じで、「カテゴリーは記事が載った連載で決まっています」と一言添えた。

- DeepSeek（deepseek-flash、思考なし）: 6,263 件で 129.0 秒（48.5 件/秒）。入力 45,169,500 トークン（うちキャッシュ 41,839,488）、出力 52,345 トークン、形式不正 0 件。プロンプトが約 1 万文字に増えたが、ほとんどキャッシュに乗った
- 結果: [03_results/04_livedoor/02_distill_shots5.md](../03_results/04_livedoor/02_distill_shots5.md)

| 評価用での正解率 | 例なし | 例 5 件ずつ |
| --- | --- | --- |
| 先生（DeepSeek） | 0.643 | **0.707** |
| DeepSeek のラベルで学習した判定機（5,159 件） | 0.650 | **0.713** |
| 同じ判定機で確信度 0.9 以上（回答率 / 正解率） | 0.522 / 0.804 | 0.563 / 0.842 |
| 例の 45 件だけで学習した判定機 | – | 0.573〜0.603（C による） |
| 正解のラベルで学習した判定機（500 件 / 5,159 件） | 0.793 / 0.874 | 同じ |

- 例を見せると、先生も蒸留した判定機も 6 ポイントほど上がった。上がったのは一般ニュース（F1 0.540 → 0.671）、男性向け（0.422 → 0.569）、独身女性のコラム（0.592 → 0.702）、IT（0.472 → 0.559）。「一般ニュース」への流れ込みが減った（家電 → 一般ニュース 44 → 30 件、独身女性のコラム → 一般ニュース 25 件 → 上位 10 から外れた）
- 家電・IT・スマートフォンの取り違えは残った（家電 → IT 26 件、家電 → スマートフォン 24 件、IT → スマートフォン 26 件）。例 5 件では境目が伝わらない
- **同じ 45 件をそのまま判定機の学習に使うと 60% 前後**。DeepSeek を通して 5,159 件に広げると 71% になる。少数の例しか用意できないなら、LLM で広げる意味はある
- ただし正解のラベルを 500 件用意できれば 79% で、few-shot の蒸留（71%）より高い。livedoor のように境目が編集方針で決まるカテゴリーでは、人が数百件付けるほうが効く
- 蒸留した判定機は先生をわずかに上回った（0.707 → 0.713）。先生の揺れが、たくさんの例で学習するうちにならされた可能性がある
