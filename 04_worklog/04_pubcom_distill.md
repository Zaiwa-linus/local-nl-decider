# 正解のない実データでの蒸留（パブコメの意見）

正解のラベルがない実データで、DeepSeek にカテゴリーを決めさせ、そのラベルを正解として判定機を作った。

## データ選び

- 条件: 実データで、規約上 DeepSeek に送ってよく、学習にも使えるもの
- 日本語の口コミの公開データは、Amazon（学術研究のみ・再配布禁止）、WRIME（研究目的のみ・再配布禁止）、楽天（大学などの研究者のみ）と、どれも条件に合わなかった
- **e-Gov パブリック・コメントの「意見募集の結果」の PDF を使うことにした**
  - 各省庁が、寄せられた意見の要旨と省庁の考え方を表にまとめた文書。省庁が作った文書なので、e-Gov の利用規約により公共データ利用規約（PDL1.0）で使える（出典の表示が必要。加工したら加工したことを示す）
  - 市民が書いた意見の原文（「提出された意見」などの添付ファイル）は、著作権が提出者にあるので取らない
  - robots.txt はなく、自動取得を禁じる記述もなかった。1 秒に 1 回の間隔で取得した

## 意見の取り出し（10_extract_opinions.py）

PDF の文字を pypdf で取り出し、DeepSeek（`deepseek-flash`、思考なし）に意見の要旨だけを原文のまま抜き出させた。抜き出した文が PDF に本当にあるかを、空白を除いて比べて確かめ、ないもの（書き換えられたもの）は捨てた。

| 項目 | 内容 |
| --- | --- |
| 取り出せた意見 | **8,770 件**（案件 249 件、重複を除くと 8,681 件） |
| 原文と一致した割合 | 89.8%（DeepSeek が抜き出した 9,455 件中。最初の試行分を除く） |
| 意見が 0 件だった PDF | 202 個（結果の概要だけの PDF など） |
| 読めなかった PDF | 24 個 |
| 文字数 | 中央値 122、上位 10% は 389 以上、最大 3,164 |
| 時間 | 約 10 分（16 並列） |
| トークン | 入力 約 310 万、出力 約 140 万 |

## 判定機の精度（14_train_eval_pubcom.py）

DeepSeek のラベルを正解とした。案件単位で学習用 7,387 件・評価用 1,383 件に分けた（同じ PDF の意見が両方に入らないようにするため）。ロジスティック回帰の C は、学習用の中の交差検証で 30 を選んだ。

| 項目 | 結果 |
| --- | --- |
| DeepSeek のラベルとの一致率 | **69.9%** |
| Macro-F1 | 0.487 |
| 参考: いちばん多いカテゴリー（修正の要求）を常に答えた場合 | 約 47% |

確信度別（補正なし）:

| しきい値 | 回答率 | 正解率 |
| --- | --- | --- |
| なし | 100% | 69.9% |
| 0.7 | 60.4% | 82.9% |
| 0.8 | 45.8% | 88.3% |
| 0.9 | 27.3% | **92.3%** |

学習件数と正解率: 2,163 件で 65.1%、3,819 件で 69.1%、7,387 件で 69.9%。

カテゴリーごとの F1: 修正の要求 0.79、説明の要求 0.65、反対 0.62 と、件数の多いものはそこそこ。根拠データの要求（0.00）、情報提供（0.29）、手続きへの要望（0.37）など件数の少ないものは低い。

間違えやすい組み合わせ: 説明の要求 ⇔ 修正の要求（76 件・51 件）、反対 → 修正の要求（41 件）、修正の要求 ⇔ 新しい政策の提案（33 件・28 件）。

元データ: [03_results/02_pubcom_type/02_classifier.md](../03_results/02_pubcom_type/02_classifier.md)

## わかったこと

- MASSIVE（87.5〜91%）よりかなり難しい。理由として考えられるもの:
  - カテゴリーが「話題」ではなく「意見の種類（修正要求か、質問か、反対か）」。埋め込みは話題の違いはよく捉えるが、同じ話題の中での言い方の違いは捉えにくい
  - 1 件の意見に「質問」と「修正の要求」が混ざっていることが多く、カテゴリーの境目があいまい
  - 先生（DeepSeek）のラベル自体がどれくらい安定しているか、まだ測っていない
  - 件数の少ないカテゴリーは、学習データが足りない
- それでも確信度 0.9 以上に絞ると 92.3% が出る。ただし回答率は 27% と低い
- 学習件数を倍にしても 69.1% → 69.9% とほとんど上がらない。件数より、カテゴリーの設計やラベルの質のほうが効きそう

## DeepSeek のラベルの再現性（15_label_stability.py）

無作為に選んだ意見 1,000 件に、12_label_opinions.py（`--sample 1000 --out ...`）でラベルを付け直し、最初のラベル（flash_1、判定機の学習に使ったもの）と比べた。結果は [03_results/02_pubcom_type/03_label_stability.md](../03_results/02_pubcom_type/03_label_stability.md)。

| 付け直し | 時間 | 入力トークン（うちキャッシュ） | 出力トークン | 形式不正 |
| --- | --- | --- | --- | --- |
| flash 2 回目 | 32.2 秒（31.0 件/秒） | 963,371（768,606） | 8,238 | 0 |
| flash 3 回目 | 42.3 秒（23.7 件/秒） | 963,371（768,606） | 8,233 | 0 |
| `deepseek-v4-pro`（思考なし） | 31.9 秒（31.4 件/秒） | 960,371（743,680） | 9,139 | 0 |

| 比べたもの | 一致率 | κ 係数 |
| --- | --- | --- |
| flash 1 回目 と 2 回目 | 0.964 | 0.950 |
| flash 1 回目 と 3 回目 | 0.959 | 0.943 |
| flash 2 回目 と 3 回目 | 0.989 | 0.985 |
| flash 1 回目 と pro | 0.871 | 0.821 |

- flash の 3 回がすべて同じ: 95.6%。flash の 3 回と pro がすべて同じ: 85.0%
- 同じ設定でも、temperature 0 で完全には一致しない。1 回目だけ一致率が低いのは、付けた日時（負荷やサーバー）が違うためかもしれない（2・3 回目は続けて実行）
- pro との食い違いは、修正の要求 ↔ 反対・賛成・説明の要求、新しい政策の提案 → 修正の要求 など。件数の少ないカテゴリー（根拠データの要求 46%、その他 64%、手続きへの要望 65%）ほど pro と一致しない
- 判定機（評価用に入った 172 件）: flash_1 との一致 70.9%、pro との一致 69.8%。flash の 3 回が同じ意見だけなら 72.1%、4 回すべて同じ意見だけなら 73.3%
- **わかったこと**: 先生（DeepSeek）のラベルの揺れは同じモデルで 4% 前後、モデルを変えると 13% 程度。ラベルが揺れない意見に絞っても判定機の一致率は 73% までしか上がらないので、精度が低い主な原因はラベルの揺れではなく、埋め込み＋ロジスティック回帰で「意見の種類」を見分けにくいこと

### 判定機の精度（[03_results/03_pubcom_topic/02_classifier.md](../03_results/03_pubcom_topic/02_classifier.md)）

| | 意見の種類 | 話題 |
| --- | --- | --- |
| 正解率（案件単位で分けた評価用） | 0.699 | **0.638** |
| Macro-F1 | 0.487 | 0.560 |
| 確信度 0.9 以上: 回答率 / 正解率 | 0.273 / 0.923 | 0.330 / 0.893 |
| 学習件数 25% / 50% / 100% | 0.651 / 0.691 / 0.699 | 0.523 / 0.619 / 0.638 |
| （参考）案件を気にせず無作為に分けた場合 | 0.702 | 0.781 |

- 話題のほうが正解率は低いが、Macro-F1 は高い（少ないカテゴリーも当たる）
- 意見の種類は、案件で分けても無作為に分けても同じ（70%）。話題は、無作為なら 78% なのに、案件で分けると 64% に下がる。話題は案件ごとにほぼ決まるので、学習で見たことのない案件の話題を当てるには、案件の数が足りない（防災 3 件、その他 4 件、安全保障 6 件、競争・知財 9 件）
- 学習件数を増やすと大きく伸びている（52% → 62% → 64%）。案件を増やせばまだ上がりそう
- 間違いの多くは、「行政運営・司法」（行政手続・法令文言など）への流れ込みと、環境 ↔ エネルギー、農林水産 ↔ 環境の取り違え。「行政運営・司法」は「どの分野の意見でも手続の話ならここ」なので、ほかの話題と重なりやすい
- 同じ案件の中でも、いちばん多い話題が占める割合は平均 72%。意見の本文だけでは、どの案件の話か分からないものも多い（「青少年への影響防止策」など）
