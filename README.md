# local-nl-decider

ローカルで動く Gemma の埋め込みモデル（EmbeddingGemma 2）を使い、口コミなどの自然言語テキストをグループ分けする高速な判定機を作るプロジェクト。

## 目的

- 口コミなどの自然言語テキストを、ローカル環境だけでカテゴリーに分類する
- 推論のたびに LLM を呼ばずに済むよう、「埋め込み＋軽量な分類器」で高速・低コストに判定する
- 将来的には、ラベルのないテキストでも LLM にラベルを付けさせて学習データを作り、同じ流れで判定機を作れるようにする

## 基本アイデア

```
テキスト ──▶ Gemma Embedding（ローカル） ──▶ 特徴量ベクトル ──▶ 判定機（分類器） ──▶ カテゴリー
```

- LLM の重い推論は「学習データ作り」にだけ使う
- 実際の判定は「埋め込み＋軽量な分類器」で行い、速く大量に処理する

## フェーズ

### Phase 1: ラベル付きのオープンデータで検証

1. **データ収集**
   - 日本語で、あらかじめグループ分けされた自然言語のオープンデータを使う
   - **MASSIVE（日本語、CC BY 4.0）に決定**。候補の比較は [00_knowledge/03_datasets/](00_knowledge/03_datasets/)
2. **埋め込み**
   - 口コミを 1 件ずつ EmbeddingGemma 2 でベクトル化する（環境と使い方は [00_knowledge/02_embedding/](00_knowledge/02_embedding/)）
   - 埋め込み結果はファイルにキャッシュし、何度も計算し直さないようにする
3. **判定機の構築**
   - 埋め込みを特徴量として分類器を学習する
   - まずはロジスティック回帰、k-NN などのシンプルなモデルをベースラインにし、必要なら小さな MLP や LightGBM も試す
4. **評価**
   - 学習用と評価用にデータを分けて、Accuracy / Macro-F1 / 混同行列で評価する
   - 推論の速さ（件/秒）も測る
5. **結果**: [03_results/](03_results/)。シナリオ 18 種類で正解率 91%。確信度を補正し、しきい値で絞ると約 85% を正解率 97% で自動判定できる

### Phase 2: ラベルなしデータへの展開（Phase 1 がうまくいったら）

1. ラベルのないテキストデータを用意する
2. 出力を学習に使ってよいと規約で認められている LLM（DeepSeek API など）で、テキストをグループ分けし、ラベルを付ける（蒸留）
   - カテゴリーの定義（名前と説明）も LLM と一緒に決める
   - **jev の出力は学習データに使えない**。jev の規約（§2.3(b)）で、出力をまねるようにモデルを学習させることが禁止されているため（詳しくは [00_knowledge/01_jev/](00_knowledge/01_jev/)）
   - jev は、ローカルの判定機の確信度が低かったものの判定に回す、という使い方なら問題ない
   - 確信度が低いものは学習データから外すか、人が確認する
3. LLM が付けたラベルを学習データにして、Phase 1 と同じ流れで判定機を作る
4. LLM のラベルと判定機の出力がどれくらい一致するか、またコストと速度がどれくらい改善するかを評価する

## 要件

### 機能要件

- テキストを 1 件ずつ、またはまとめて埋め込みベクトルにできること
- 埋め込みを使って分類器を学習・保存・読み込みできること
- 新しいテキストに対してカテゴリー（と確信度）を返せること
- 評価用のスクリプトがあること（指標と混同行列を出力する）
- Phase 2: LLM でラベルを付けて学習データを作るパイプラインがあること

### 非機能要件

- **ローカルで完結すること**: 埋め込みと判定は外部 API なしで動く（外部 API の jev や Claude を使うのは Phase 2 のラベル付けだけ）
- **高速であること**: 大量の口コミを短時間で判定できる
- **再現できること**: データの取得、埋め込み、学習、評価をスクリプトで再実行できる
