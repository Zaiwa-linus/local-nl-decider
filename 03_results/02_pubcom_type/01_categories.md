# パブコメの意見のカテゴリー（意見の種類、DeepSeek が設計）

意見 300 件をランダムに見せて、deepseek-v4-pro（思考あり）に設計させた。

| 名前 | ID | 説明 |
| --- | --- | --- |
| 説明の要求 | `clarification_request` | 提案・文書の意味、定義、適用範囲、判断基準、具体例、運用方法などについて説明や確認を求める意見。特定の条文・用語・条件が何を指すか分からない場合や、想定ケースを問うもの。変更の提案ではなく、理解のための質問が主眼。 |
| 修正の要求 | `amendment_request` | 対象文書・計画・規則案の内容自体に変更（追記、修正、削除、要件変更、明記、義務付け、期間設定など）を求める意見。提案の政策実質に影響する内容の変更や、特定の条項・様式・基準への具体的な追加・修正を含む。純粋な字句修正は editorial_correction、新たな政策体系の提案は new_policy_proposal、単なる反対は policy_opposition に分類。 |
| 賛成 | `policy_support` | 提案された政策・改正案・方針に対して賛成、同意、支持、肯定的評価を表明する意見。主眼が現案への賛成・容認にあり、変更要求を伴わないもの。異議がない旨、歓迎する旨、妥当とする旨なども含む。 |
| 反対 | `policy_opposition` | 提案された政策・改正案・方針に対して反対、不同意、中止・撤回要求、問題視、否定的評価を表明する意見。主眼が現案への反対・拒否にあり、代替案の提示を伴っていても現案否定が前面のものはここ。 |
| 情報提供 | `evidence_sharing` | 政策判断の参考となる個人的体験、事例報告、事実情報、統計・データ、研究成果などを提供する意見。主眼が情報提供にあり、特定の変更要求や賛否表明が前面に出ないもの。 |
| 誤字・表記の指摘 | `editorial_correction` | 誤字脱字、文法・日本語の不自然さ、用語の不統一、条文番号・引用の誤り、重複・欠落、読みやすさのための表現修正など、政策内容を変えない文書上の修正を指摘・提案する意見。政策的意味が変わる表現変更は amendment_request に分類。 |
| 手続きへの要望 | `process_request` | 意見募集期間の延長、情報公開・透明性の確保、国会審議、地元住民・利害関係者との協議、説明会開催、利益相反の防止、第三者検証、説明責任など、意思決定や制度運用のプロセス改善を求める意見。文書内容の変更ではなく、手続・ガバナンスに関する要求。 |
| 根拠データの要求 | `data_request` | 提案の根拠となるデータ、統計、費用対効果分析、リスク評価、環境影響評価、数値目標、科学的証拠などの提示・検証を求める意見。定義・意味の確認ではなく、裏付けとなる情報を求めるもの。 |
| 新しい政策の提案 | `new_policy_proposal` | 対象文書の条項修正ではなく、新たな政策・制度・事業・支援措置・規制の創設や抜本的な政策転換（例：再公営化、新法制定、補助金制度の新設）を提案する意見。現案への賛否より、新しい取組の提案が主眼。 |
| その他 | `other` | 上記のいずれにも該当しない意見。単なる謝辞・承知の表明、議事録的コメント、意味が不明または分類不可能なもの。 |
